# 客观陈述：设定正文写法

适用于世界书里的人物设定、世界与制度设定、机制规则，以及卡文本字段里的设定部分。开场白、对话示例和角色心里话属于叙事文本，不按这份写。

用户或卡片说明明确要求叙事式设定、第一人称档案或其它风格时，按用户要求来，这份只作参考。

## 为什么要这样写

模型读设定时，学到的不只是事实，还有语气。设定里叙述者在点评人物（「起得猛」「拖不住」「图的东西很实在」），模型写正文时也会用同样的口气点评，句子越写越像旁白在下结论。设定写成客观陈述，模型拿到的是可以执行的事实，语气留给开场白和预设去定。

客观陈述的另一个作用是可检查：每句话都能问「什么情况下、谁、做什么」，答不出来的句子就是信息不足。

## 一句话里要有什么

每条设定尽量写全这四样，缺哪样补哪样：

| 成分 | 说明 | 例子 |
| --- | --- | --- |
| 主语 | 谁做的，写名字或明确的称呼，不靠上下文猜 | 姜栀、魏有德、玫瑰十字会部员 |
| 条件 | 在什么场合、什么情况下 | 被当面叫「人妖」时、拍摄时、熄灯后 |
| 行为 | 可观察的动作或明确的决定 | 笑一下，之后不再理对方 |
| 频率或程度 | 常常、偶尔、每次、从不；或者给出可核对的范围 | 每天早上、每月一次、多数时候 |

「被当面叫『人妖』时会笑一下，之后不再理对方」四样都有。「雷点很多，一碰就炸」四样都没有。

## 改写规则

### 1. 评价换成依据

叙述者的评价（好看、厉害、实在、狠）不给模型任何能执行的东西，把评价背后的事实写出来。

- 「腿是全身最好看的一条」→「腿长、直、匀称，从胯到脚踝线条连贯」
- 「手段很高明」→「先用成绩逼对方答应，再用推荐信让对方不敢说出去」
- 「图的东西很实在」→「主要追求外貌上的认可、金钱和性快感」

### 2. 态度短语拆开，补上省略的部分

「起得猛」「拖不住」「一概不问」「喜欢就做」「嫌归嫌」这类短语，压缩掉了对象、条件和后果，只剩叙述者的态度。拆开时问三个问题：谁？对什么？结果是什么？

- 「起得猛」→ 什么起得猛？→「成年后开始，最早见面的对象是买主」
- 「拖不住」→ 谁拖不住？拖什么？→「决定后通常立即执行，他人劝阻效果有限」
- 「嫌归嫌，账算得过来就让他做」→「厌恶他，但在权衡利弊后会同意」

### 3. 心理写成动机或可观察的表现

可以直接写动机（「需要通过他人的评价确认自我价值」），也可以写表现（「被夸到在意的地方会笑出来，之后明显得意」）。不写叙述者替人物总结的人生道理。

- 「他从那时起就知道穿裙子能换来什么」→「客人称赞时母亲会露出笑容，他便会主动去换下一条」
- 「能信的只有对方」→ 删掉，前面的经历已经说明了

### 4. 一个事实只写一次，写在对应的字段

性格写行为倾向，背景写经历，性经验写性经历，行为风格写说话和动作习惯，关系网写每段关系的内容。不要在每个字段末尾再回头总结一遍性格，也不要在背景、性经验、关系网里把同一件事各写一遍。

### 5. 对仗、排比、比喻评价改成平铺

- 「与其说是兄妹，不如说是闺蜜」→「共用一个衣柜和一套化妆品，互相借内衣，彼此无话不谈」
- 「吵架做、高兴做、被弄得不舒服回来也做」→「私下发生关系的次数多于拍摄时；他被客人弄得不舒服回来，妹妹会先抱着他，再和他做到他睡着」
- 「走路像一朵慢慢漂移的云」→「步子小而慢，裙摆随步伐摆动」

外貌里描述形状、质地的比喻（「乳头像两颗小樱桃」）可以留，它承载的是外形信息；评价性的比喻（「像瓷偶一样让人不忍心碰」）改掉。

### 6. 程度词换成范围或频率

- 「极其敏感」→「乳头一碰就硬」
- 「经常被叫住拍照」→「在走廊被叫住合影是常事，每周都有」（有把握才写数字）
- 「很有钱」→「这两年的收入高于同龄人，主要花在衣服和化妆品上」

没有依据就不编数字。「多停了两秒」「缩了半寸」这种精确到不必要的数字也去掉。

### 7. 直白词照用

客观不等于委婉。设定里原本用的身体部位和性行为词汇保持原样，不换成「那里」「私处」「亲密行为」。删掉的是叙述者的态度，事实和用词都保留。

### 8. 台词样本原样保留

「」里的口头禅、方言、英文夹杂是角色语气的样本，模型要靠它们学说话方式，不改写成陈述句。只改引号外面的叙述。

## 各字段怎么写

| 字段 | 写什么 | 常见问题 |
| --- | --- | --- |
| 性格 | 性格代码后面逐条写行为倾向：在什么情况下通常怎么做 | 写成形容词串（「沉稳聪明，外冷内热」）；写成叙述者的总评 |
| 身份 | 年级、职务、宿舍号等可核对的信息 | 混进评价（「人气超高的校花」可以写成「校花，戏剧部核心演员」） |
| 性癖/XP | 偏好什么、在什么条件下更兴奋、接受和不接受的范围 | 「什么都玩」这种空话；省略具体玩法 |
| 背景故事 | 按时间写经历，每段经历写清时间点和结果 | 段末金句；戏剧化结论；把经历改写成人生感悟 |
| 青春日常 | 一天里各时段做什么 | 写成氛围描写 |
| 性经验 | 起始时间、对象、频率、和谁是什么关系 | 「起得早」「玩得开」这类态度短语 |
| 行为风格 | 说话特点、常用称呼、口头禅、习惯动作、特定情况下的反应 | 神态模板（「嘴角微勾」）；只写气质不写动作 |
| 穿着风格 | 款式、颜色、场合差异 | 写成审美评价 |
| 外貌特征 | 尺寸、形状、颜色、质地、可见的痕迹 | 「最好看」「绝美」「让人移不开眼」 |
| 弧光方向 | 欲望、恐惧、成长方向都写成会发生的具体事情 | 鸡汤式成长（「学会做自己」） |
| 关系网 | 每个人一句：关系类型、相处方式、双方掌握的筹码 | 只写标签（「互相利用」）不写怎么利用 |

## 改写步骤

1. 先通读整个条目，把所有事实列出来：人名、时间、数字、地点、关系、经历、身体细节。改完后逐条对照，一条都不能少。
2. 逐句检查：主语、条件、行为、频率齐不齐；有没有叙述者的评价或态度。
3. 改写有问题的句子。只改表述，不改事实；拿不准原意时，按最直接的字面意思写，并告诉用户。
4. 删掉总结句、重复的性格总评和重复事实。
5. 对照第一步的清单检查事实，再检查字段键名、层级和顺序没有变。

## 不要改过头

改成客观陈述以后常见的几种毛病：

- **公文腔**：「该角色具有较强的依赖倾向」「其行为模式表现为……」。主语直接用名字，动词用具体动作：「姜栀坐着时习惯靠着人」。
- **满篇「倾向于」「通常会」**：确定的事直接写，不确定的才加限定。
- **删掉信息**：觉得一句话有态度就整句删掉，事实也跟着没了。应该拆开重写，不是删。
- **委婉化**：把直白的词换成文雅的说法，模型写正文时也会跟着变委婉。
- **改动台词**：把「」里的口头禅改成陈述句，角色的说话方式就没了。
- **所有人写成一个样**：客观的是叙述口吻，人物之间的差别要保留。改完以后把两个角色的同一字段放在一起读，读不出区别就是细节丢了。

## 完整示例

改写前：

```yaml
性格: 靠别人的目光确认自己在；情绪是拿来用的，什么时候该软什么时候该硬心里有数；想干什么就干什么，拖不住；有一条自己的线，碰了就翻脸。图的东西很实在——好看、钱、被人夸、做得爽，摆在最前面。对外甜软爱撒娇，转过身算得清清楚楚。
```

改写后：

```yaml
性格: 需要通过他人的注视和评价确认自我价值。会有意识地控制情绪表达，根据场合选择示弱或强硬。行动由个人兴趣驱动，决定后通常立即执行，他人劝阻效果有限。有明确的个人底线，被触碰时会当场翻脸。主要追求外貌上的认可、金钱、他人称赞和性快感。对外表现甜软、爱撒娇；私下对利益得失计算清楚。
```

原文里每个意思都还在：确认自我、控制情绪、想做就做、底线、追求的东西、内外反差。变化在于每句都能回答「他在什么情况下怎么做」。

## 交给其它模型改写时

其它模型（包括本工作区以外的 AI）按这份规范改写时，把下面这段和本文件一起给它，比只说「写客观一点」有效：

```text
把下面的人物设定改写成客观陈述。
- 每句写清主语、条件、行为，能写频率就写频率。
- 删掉叙述者的评价和态度，把评价换成背后的事实。
- 事实一条不删、不新增；改完逐条对照原文检查。
- 不写总结句、对仗句、「不是A而是B」、比喻式评价。
- 直白的身体和性词汇照原样保留，不换成委婉说法。
- 「」里的台词、口头禅、方言原样保留。
- YAML 的字段键名、层级、顺序不变。
- 只输出改写后的全文，再另起一段列出拿不准的句子（原句→改后）。
```

改完后用 [固定文风自查](anti-template.md) 末尾的正则搜一遍，命中的句子逐条判断。
