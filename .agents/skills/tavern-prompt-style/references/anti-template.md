# 固定文风自查

写或改人物条目、开场白、对话示例、规则文本之后，用这份清单过一遍。它针对的是模型写中文时常见的固定写法：句式、总结句、神态动作和语气先定好，内容往里填。

## 判据

一句话有没有问题，看它的形式是不是脱离了内容。某种修辞出现过，不等于它就是坏句子：对仗、短句、比喻都能用，问题出在每段都用、用来代替具体信息，或者换掉主语照样成立的时候。

三个试验，任选其一：

- **删除**：删掉形容词、副词和修饰从句，意思没少，删掉的就是装饰。
- **反转**：把「不是 A，而是 B」换成「不是 B，而是 A」，读起来也通顺，这个对仗就没有承载判断。
- **替换**：把人名换成卡里另一个角色，句子照样成立，它就没写到这个人。人物设定最该用这一条。

## 人物设定条目

条目给模型看，模型会照着设定的语气写正文。设定里每有一句总结金句，正文里就会多出一堆同样的句子。

| 写法 | 例子 | 改法 |
| --- | --- | --- |
| 段末总结、提炼人生道理 | 「兄妹俩从小学会的是：夸奖和钱都能换，身体也能换；能信的只有对方。」 | 删掉。前面的事实已经说明了，让模型从事实里推出来 |
| 对仗定性 | 「与其说是兄妹，不如说是闺蜜」 | 写成具体的事：「共用一个衣柜、一套化妆品，互相借内衣」 |
| 否定-更正 | 「不图钱、不图被夸，图的是好玩」 | 只说她要什么：「对钱没概念，被夸也不往心里去；她要的是好玩」 |
| 三连排比 | 「吵架做、高兴做、被弄得不舒服回来也做」 | 留一个最有信息的场景，写具体：「被客人弄得不舒服回来，她先抱着他，再做到他睡着」 |
| 戏剧化结论 | 「那晚之后两个人再也没分开睡过」「那是他见过的唯一好脸色」 | 写成可以核对的事实：「住进510以后也睡一张床」「客人夸一句，母亲才露个笑脸」 |
| 鸡汤式弧光 | 「成长方向＝发现自己也可以不只是某某的妹妹」 | 写成一件会发生的事：「开始用自己的小号接单，哥哥不在也敢一个人去见人」 |
| 反差金句 | 「眼睛和哥哥不像，笑起来却一模一样」 | 只写差别：「眼尾往下垂，哥哥的是往上挑的」 |
| 模板字段硬填 | 体味、走姿写成谁都能用的「淡淡的清香」「步伐轻盈」 | 字段沿用卡里已有结构；没东西可写就写短，写不出这个人特有的东西宁可只留一句 |

同一个事实只在一个字段写一次。性格字段写行为倾向，背景写经历，不要每个字段末尾都回头总结一遍性格。

## 开场白与叙事

| 写法 | 例子 | 改法 |
| --- | --- | --- |
| 神态程式化 | 「嘴角微勾」「眼底掠过一丝……」「喉结滚动」「指节泛白」 | 换成这个人此刻在做的事：她把薯片往床上一摔 |
| 断奏切镜头 | 「他停住了。很久。没有回头。」 | 普通动作连起来写；一段最多一次需要停顿的短句 |
| 议论代替叙事 | 「这一刻，他终于与自己和解。」 | 删掉，写他接下来做了什么 |
| 隐喻惯用化 | 「接住情绪」「安放委屈」 | 写具体的回应：他把她拉到身边，没再问 |
| 伪精确 | 「多停了两秒」「缩了半寸」 | 去掉数字，或者换成看得见的动作 |
| 超长前置定语 | 「一声练出来的女声都兜不住的低哼」 | 拆开：「一声低哼，练出来的女声没兜住」 |
| 意象和领域词堆砌 | 把物理、医学、程序术语当调料 | 只用这个场景里的人会用的词 |

## 台词与心里话

| 写法 | 例子 | 毛病 |
| --- | --- | --- |
| 对举、姿态化口语 | 「你继续闹，我接着。」 | 用整齐的台词塑造强势形象，没回应具体的事 |
| 许可语气 | 「你想走，我不拦。」「够你用了，不够再来。」 | 默认说话人有权批准，没有关系铺垫时显得居高临下 |
| 让步式重复 | 「累就累吧，错就错吧。」「你骂得对。」 | 敷衍，或刻意表现无所谓 |
| 先否定再重释 | 「你不是难过，你只是终于清醒了。」 | 否定对方已经说出的感受，再替对方下定义 |
| 拍板式认领 | 「这条我认。」「我记下了。」 | 宣判语气，替对方结束话题 |
| 标榜坦诚 | 「说实话」「说白了」「有一说一」 | 删掉，直接说那句话 |

台词要回应眼前的具体事情，带出这个人的口音、用词和在乎的东西。同一张卡里几个角色说话的句式一样，就是写成了一个人。

## 规则与机制文本

- 不用万能动词和名词化：「进行优化」「实现提升」「完成一次情绪锚定」，改成具体做什么、改了什么。
- 不用无信息的程度词：极其、显著、深度、彻底、堪称。
- 术语用卡里和宿主约定的叫法，不自造字面译名。

## 弹幕、论坛等「观众声音」

只适用于卡里设计了弹幕、评论区、论坛帖这类观众文本的情况，没有就跳过。这类文本要碎、要口语。常见问题是写成影评：复述正文、引用长台词、分析人物，昵称写成「考据党」「纯爱战士」这类分类标签。弹幕多数两到十五个字，昵称像随手起的网名，结构每批不同。

## 不算问题的写法

- 结构清楚、分点、YAML 缩进本身不是问题；问题是每点等量展开、每段都落到一句金句上。
- 信息密度高、句子短、判断明确，都是好的。
- 角色本人的口头禅、用户指定的修辞风格、原卡已有的文体，保留，不以「去 AI 味」为由改写。
- 正文里偶尔一次对仗或短句断奏，用在真正需要的地方，可以留。
